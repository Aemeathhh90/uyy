# KakaAnime Dantotsu UI Baseline

Temporary baseline branch: `baseline/dantotsu-ui`.

Purpose: use the Dantotsu implementation as a visual/interaction baseline for Home and Anime Detail while we progressively remove unrelated KakaAnime-incompatible features.

This branch is for development/testing only. Dantotsu is GPLv3 and its upstream README contains a warning about app-store distribution; review the license and upstream notice before any redistribution.
